# Security reporting

OpenTapeout 0.1.0 is an alpha, not independently audited or foundry-qualified. Read [the security model](docs/SECURITY.md) before using real design data.

Use the repository's private vulnerability-reporting channel when enabled. If that channel is unavailable, request a private contact from the maintainer without disclosing exploit details, private design data or secrets in a public issue. No monitored security email address or response-time SLA is claimed.

Only the current development version is targeted for fixes; no long-term-supported release exists yet. Keep deployment access private until real-flow qualification and independent review are complete.
